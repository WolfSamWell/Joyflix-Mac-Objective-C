# Joyflix Tauri

基于 Tauri 的跨平台视频浏览器，支持 Windows 和 macOS。

## 功能

- 🎬 内置多个视频站点
- 📋 观影历史记录
- 🔍 网站状态监控
- 🚫 广告拦截
- 🔴 一键全屏播放（红色按钮）

## 下载

从 [Releases](../../releases) 页面下载最新版本：

- **Windows**: `Joyflix_x.x.x_x64.msi`
- **macOS (Intel)**: `Joyflix_x.x.x_x64.dmg`
- **macOS (Apple Silicon)**: `Joyflix_x.x.x_aarch64.dmg`

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 打包
npm run build
```

## 技术栈

- Tauri 2.0
- Rust
- JavaScript (原生)
